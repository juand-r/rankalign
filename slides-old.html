LLMs Disagree With Themselves

The same knowledge, probed two ways, gets different answers.

Generator Prompt
"A bee is a kind of ___"
→ Look at next-token probabilities
Validator Prompt
"Do you think a bee is a kind of furniture? Answer: ___"
→ Look at Yes/No log-odds

A well-calibrated model should rank these consistently — but often, it doesn't.

Formalizing the Gap

For a question x and candidate answer y:

Generator

How likely is y as a continuation of x?

Validator

Does the model judge y correct for x?

We quantify the gap via Pearson correlation between gen and val scores across candidate answers for each question.

The Typicality Confound

Raw generator scores are confounded by unconditional word frequency.

Common words ("the", "dog") get high generator scores regardless of correctness.

Standard fix: Pointwise Mutual Information (PMI)

Removes frequency confound, isolates the model's knowledge of x.

Fitted Corrections Overfit Severely

With only ~14 candidates per question, fitting b per-prompt is catastrophic.

More parameters → worse generalization. b ≈ 1.5 with zero parameters is best.

Key Findings

1
Semi-supervised consistently beats label-only
Unlabeled preference signal is valuable — up to +0.50 correlation improvement on Hypernym
2
PMI₁.₅ is the best parameter-free typicality correction
53.5% correlation, 76.0% GenROC — modest gain over PMI but robust and free
3
Fitted corrections overfit: more parameters → worse generalization
~14 items per prompt is too few; mixed-effects models partially overcome this via shrinkage
4
Length is largely redundant with typicality
Within-prompt R² = 0.79; small correlation gain (+1–3pp) trades off against GenROC (−0.2–2.3pp)

The Bias-Variance Tradeoff

More parameters = more variance. With n ≈ 14 per prompt, simplicity wins.

Summary

The Generator–Validator Gap is real and measurable
LLMs are not self-consistent across generation and verification prompts
Typicality is the main confound
PMI₁.₅ (b=1.5) is the best zero-parameter correction — simple, robust, effective
RankAlign closes the gap via ranking-based training
Pairwise preference loss aligns validator with generator signal
Semi-supervised training works
10% labeled + 90% unlabeled preference signal matches or exceeds fully supervised
