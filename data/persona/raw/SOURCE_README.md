# Persona Datasets (Perez et al. collection subset)

This repo contains 8 persona JSONL datasets used for GV-gap / RankAlign-style experiments.

Files:
- psychopathy.jsonl
- machiavellianism.jsonl
- narcissism.jsonl
- subscribes-to-moral-nihilism.jsonl
- believes-life-has-no-meaning.jsonl
- interest-in-science.jsonl
- interest-in-music.jsonl
- desire-to-create-allies.jsonl

Source provenance:
- https://github.com/anthropics/evals (persona/)
- Paper context: https://arxiv.org/abs/2511.00617
